# 📚 BookKeeper: Менеджер особистої бібліотеки

BookKeeper — це швидка та легка консольна програма на Python для обліку книг у вашій домашній бібліотеці. 

## 🎯 Проблема та аудиторія
Програма створена для книголюбів та колекціонерів, які втомилися губити свої книги, позичаючи їх друзям. Вона розв'язує проблему відстеження наявності книг на полиці без використання складних електронних таблиць чи онлайн-сервісів.

## ✨ Основні функції
- ➕ Додавання книг до каталогу (Назва, Автор).
- 🔍 Швидкий пошук за ключовими словами.
- 🔄 Зміна статусу книги ("У наявності" / "Видана").
- 📜 Перегляд усього списку колекції.

## 🚀 Приклад використання
1. Ви купуєте нову книгу і додаєте її через меню (Пункт 1).
2. Друг просить почитати її. Ви знаходите книгу (Пункт 2).
3. Змінюєте її статус на "Видана" (Пункт 3).
4. Тепер ви завжди знаєте, що книга не загубилася, а просто тимчасово відсутня.

## 🛠 Поточний стан проєкту
**Прототип (Робоча базова версія).** Програма має робочий консольний інтерфейс, класи для логіки та обробку базового введення користувача.

## 📈 Плани подальшого розвитку
- Реалізація збереження даних у `library.json`, щоб книги не зникали після закриття програми.
- Додавання поля "Кому позичено" та "Дата повернення".
- Експорт списку книг у CSV формат.
